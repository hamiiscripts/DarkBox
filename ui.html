Security

Change the pattern or passcode that opens this panel and your folders.

Lock All Folders locks every open folder immediately, wherever it is. Tip: Ctrl + Shift + L does the same from anywhere in Windows.

Fake mode (decoy)

Set a separate decoy pattern or passcode — different from your real one. Whoever enters it sees a harmless fake panel with fake folders, and a folder unlock opens an empty decoy folder instead. Your real folders stay hidden, and every decoy use is recorded in Activity.

New folders use High End Lock (AES-256) by default
Just Lock is the default — fast, the folder is moved to the vault and hidden. Turn this on if new folders should use High End Lock instead, with AES-256 encryption. High End is much slower on big folders and low-end PCs. You can change the mode for any folder from its lock icon.

Recovery

If you ever forget your pattern and passcode, a recovery option is the only way back in — without it, locked folders cannot be opened. Set at least one.

Intruder photo
On the 3rd wrong try the webcam quietly takes a photo — it appears in Activity. After 5 wrong tries, input freezes for 30 seconds.

Settings

How the locker behaves in the background.

Run in the background at startup
A small tray agent starts with Windows and watches your folders.
Re-lock open folders at startup
Any folder left open is locked again when the agent starts.
Auto-lock when a folder window closes
The moment you close an unlocked folder's window, it locks itself.
Lock everything when the PC locks
Locking Windows — or putting it to sleep — locks every open folder at once.
Auto-lock open folders after
A folder left open locks itself when the time runs out — even if its window is still open.
Sound effects
Soft clicks when folders lock and unlock.
Quick-lock hotkey
Press it anywhere in Windows to lock every open folder instantly.
CTRL + SHIFT + L
"Lock with DarkBox" in Explorer
Right-click any folder in Windows Explorer to lock it with DarkBox.
Lite mode (smooth on slow PCs)
Turns off blur effects, heavy shadows and animations so DarkBox stays fast on weak computers. It turns itself on automatically on small PCs — change it here any time.

Backup & restore

Save an encrypted backup of your lock settings, folder list and activity — protected by a backup password. Keep it somewhere safe; it is the other way back if this PC's settings are ever lost.
